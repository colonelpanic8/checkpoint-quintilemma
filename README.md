# The Consciousness Checkpoint Quintilemma

This repository contains a LaTeX essay by Ivan Malison on the Checkpoint
Quintilemma.

The generated PDF is published to GitHub Pages:
<https://colonelpanic8.github.io/checkpoint-quintilemma/>

Build with:

```sh
just build
```

Or through Nix:

```sh
nix build .#checkpoint-quintilemma
```
