# The Checkpoint Quadrilemma

This repository contains a LaTeX essay by Ivan Malison on the Checkpoint
Quadrilemma.

The generated PDF is published to GitHub Pages:
<https://colonelpanic8.github.io/checkpoint-quadrilemma/>

Build with:

```sh
just build
```

Or through Nix:

```sh
nix build .#checkpoint-quadrilemma
```
